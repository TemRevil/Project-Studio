## SFX LIBRARY

| File | Triggered By |
|---|---|
| `paper_rustle.mp3` | Any element entering the scene |
| `whoosh_soft.mp3` | Slide wipe transition |
| `teal_appear.mp3` | Teal element revealing |
| `pop_gentle.mp3` | Text word appearing (very subtle) |
| `paper_fold.mp3` | Scene exit |
| `click.mp3` | Emphasis beat, smash cut |

---

## VOLUME RULES

```
SFX volume:           18–22%
SFX under voice:      reduce to 10%
Multiple SFX at once: never — stagger by minimum 4 frames
```
