# ANIMATION.md — Project Studio 1.0
## Video Type: Animation

---

## WHAT THIS IS

Character-driven. Temy's papercraft avatar is present and reacting.
The character is not performing — he's explaining.
Visuals build around him as he talks.
Best for: conceptual explanations, analogies, anything where a "guide" helps the viewer.

---

## SCENE STRUCTURE

Every scene has three beats:

```
BEAT 1 [0–20% of scene] → Setup. Character enters or is present. Visual hint appears.
BEAT 2 [20–80% of scene] → Explanation. Key visual builds. Character expression shifts.
BEAT 3 [80–100% of scene] → Resolution. Teal element appears or reveals. Character reacts.
```

---

## REQUIRED ELEMENTS PER SCENE

- Character: present with correct expression (see character.md)
- Background: cream base with paper texture
- At least one papercraft visual element (diagram, icon, label)
- Text label: one key term or phrase, max 4 words
- Teal element: appears only at the concept reveal beat

## LAYOUT GRID

For 9:16 (reel):
```
Top safe zone:     150px — NO elements (Instagram UI)
Bottom safe zone:  200px — character base zone
Left margin:        60px
Right margin:       60px
Character zone:    bottom 40% of canvas, right-aligned by default
Visual zone:       top 50% of canvas, left or center
Text zone:         center of canvas, always foreground layer
```

For 16:9 (video):
```
Top safe zone:      80px
Bottom safe zone:   80px
Character zone:     right 35% of canvas, vertically centered
Visual zone:        left 55% of canvas
Text zone:          center-bottom area
```

---

## CHARACTER USAGE IN THIS TYPE

- Expression switches at each beat transition
- Always starts with idle or thinking
- Ends scene on talking or pointing if narration continues
- Ends video on laughing or idle (never mid-expression)
- See character.md for full expression library and Remotion implementation

---

## WHAT ANIMATION TYPE IS NOT

- Not a cartoon with fluid movement — this is papercraft, not 2D animation
- Not character lip-sync with audio — expression switching only
- Not character walking or dramatic movement — slide in/out, spring, nothing more
- Not scene without character — if you're not using the character, use motion.md or slides.md
